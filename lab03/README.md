# Lab03 - Bash Scripting

## GenAI Usage

ChatGPT was used as an AI-assisted editing and review tool during this lab.

I used ChatGPT mainly to:
- review my existing Bash scripts;
- help me understand error messages when testing the scripts;
- check whether my comments were clear and appropriate;
- explain Bash concepts that were already present in the lab template, such as command-line parameters, if statements, pipes and redirect append;
- check whether my completed scripts met the exercise requirements.

## Prompts used

Examples of prompts/questions I used:
- How can I check whether my Bash script is working correctly?
- What does this Bash error message mean?
- Are the comments in my script clear enough?
- Does my script satisfy the requirements of Exercise 1 / 2 / 3?
- Why does Bash show an error near "done"?

## Changes made after AI review

After reviewing my work with ChatGPT, I:
- corrected a syntax error caused by a remaining `done` statement after removing a loop;
- checked and improved some comments in the scripts;
- tested the scripts again with different input values;
- verified that the log file used append redirect correctly and included date/time information.

The final scripts were tested by me directly in the Linux VM.

## Reflection

This lab helped me understand how Bash scripts use command-line parameters, conditional statements, pipes and output redirection.

I tested the scripts with different values to make sure that both possible conditions worked correctly. I also checked the log file manually to confirm that new entries were appended rather than overwriting previous entries.

Using AI as a review and troubleshooting tool helped me understand the errors I encountered and check the clarity of my work.
